# 知识库

知识库是橘记的核心概念：**一个知识库 = 一个你授权的本地目录**。

## 基本行为

- 笔记以普通 Markdown / TXT 文件保存在你选择的目录里。
- 橘记会为知识库建立全文索引，并在工作台里展示目录树。
- 可以同时添加多个知识库，各自独立授权。
- 移除知识库授权**不会删除**磁盘上的原文件。

## 项目级 Agent 说明：`AGENTS.md`

在知识库**根目录**放一个 `AGENTS.md`，它就作为这个知识库的项目级 Agent 说明。

橘记会在每次对话时自动读取它，用来告诉 Agent 这个知识库的约定，例如：

```markdown
# 我的知识库约定

- 新笔记统一放在 `inbox/` 下，文件名用 `YYYY-MM-DD-主题.md`
- 日记类内容不要自动改写
- 引用其他笔记时使用相对路径
```

::: tip 兼容旧文件
早期版本使用 `ORANGE_AGENT.md`，橘记仍然兼容读取。
:::

## 文件类型

| 类型 | 可编辑 | 说明 |
| --- | --- | --- |
| Markdown（`.md`） | ✅ | 主力的笔记格式，参与全文索引 |
| TXT（`.txt`） | ✅ | 纯文本笔记 |
| DOCX | ❌ | 只读，读取时返回提取的文本和结构块 |
| PDF | ❌ | 只读，读取时返回提取的文本和页码 |

DOCX / PDF 可以作为资料被读取，但不会被改写。

## 相关设置

- **设置 → 知识库管理**：添加、移除、重扫知识库，打开项目说明文件，管理知识库记忆。
- **设置 → 语义检索**：为知识库开启向量索引和混合检索，见 [语义检索](/features/semantic-search)。
