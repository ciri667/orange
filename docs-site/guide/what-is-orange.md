# 橘记是什么

橘记（Orange）是一款**本地优先**的 Agent 笔记应用，面向个人知识工作。

它把你自己选择的本地目录当作知识库，在桌面工作台里提供检索、问答、改写、草稿生成和知识整理能力。

## 三条设计原则

### 1. 笔记还是你的本地文件

橘记不发明自己的笔记格式。知识库就是磁盘上的一个目录，笔记是普通的 Markdown / TXT 文件。

- 移除知识库授权**不会删除**原文件。
- 随时可以用任何编辑器、任何同步盘打开这些文件。
- 数据和备份策略由你自己决定。

### 2. Agent 只在授权范围内工作

每次会话都要明确当前可用的知识库范围。Agent 的检索在 SQL 层直接按授权知识库过滤，不会越界。

会话还可以开「计划模式」：Agent 只用只读工具探索，先给出编号执行计划，你确认后才执行改动。

### 3. 所有写入先给你看 diff

由 Agent 发起的 Markdown 写入，一律走这条链路：

```
生成 diff → 路径校验 → 内容 hash 校验 → 用户确认 → 原子写入
```

不存在「Agent 悄悄改了你的文件」这种情况。

## 适合谁

| 你是 | 橘记能帮你 |
| --- | --- |
| 习惯用 Markdown 记笔记的人 | 让 Agent 在已有笔记库里检索、整理、补写，而不用把笔记导入某个封闭系统 |
| 有大量本地资料的人 | 用标题级检索和语义检索快速定位到具体段落，并拿到可核对的引用 |
| 在意数据隐私的人 | 笔记不出本机；模型密钥存系统钥匙串；语义检索可完全跑在本地 Ollama / LM Studio |
| 想在聊天软件里随手记的人 | 接入飞书 / QQ / 微信 / 企业微信，在 IM 里发起检索和写入请求 |

## 平台支持

- **macOS**
- **Windows 11**

> 前端开发服务可以单独跑在浏览器里，但本地目录访问、索引和 Agent 文件操作需要桌面端才能体验完整。
