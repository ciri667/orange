# 会话与 Agent

## 会话

一个会话是一段独立的对话上下文，绑定一组你授权的知识库。

- 会话有独立的标题、模型和上下文状态。
- 会话可以开启**计划模式**。
- 会话可以按需开启**记忆**（默认关闭）。
- 会话可以设置**安全级别**（决定 Agent 能用哪些工具）。

## 安全级别

安全级别定义工作区范围、动作能力和审批方式。新安装、未设置默认值时，本地新会话默认只读；修改默认值不影响已有会话。

| 档位 | 值 | 行为 |
| --- | --- | --- |
| 工作区内只读 | workspace-readonly | 读取、搜索所选知识库和已启用 Skill 资源，禁止生成或应用变更 |
| 工作区内修改，需审批 | workspace-write | 可提出工作区文件变更，审阅后应用 |
| 完全权限，需审批 | full-confirm | 增加工作区外资源、命令和外部服务，每次外部读取与操作审批 |
| 完全权限，无需审批 | full-auto | 同样能力范围，自动执行操作并自动应用本次新变更 |

工作区是当前会话所选知识库的真实根目录集合，不随编辑器焦点改变。前两档禁止的动作必须切档，不能通过审批临时放行。进入任一完全档须明确确认真实环境访问能力；无需审批档额外说明自动执行。

完全权限以当前系统用户为边界，不主动提权，不提供文件系统沙箱隔离。浏览器、MCP、联网搜索和 URL 抓取仅两种完全档可用，继续受各自功能设置约束。模型请求由独立的模型与隐私配置控制。

schema 裁剪和实际执行共用权限策略；权限、scope、Plan 变化会更新权限版本、取消在途审批并中断回合。执行前再核验，已有外部副作用不自动撤销。

## 计划模式

Plan 是独立开关，开启时覆盖为工作区只读，仅 search/read/list 和只读 task 可用。外部工具、命令、生成变更与所有变更应用均禁用，旧 pending 可以查看和拒绝。关闭 Plan 恢复原档位，不会提升权限。

Agent 可以先提出编号执行计划，经用户确认后退出 Plan 开始执行；执行阶段继续受原权限限制。

## 子 Agent（`task` 工具）

`task` 是唯一的编排工具，用来把一个复杂、多跳的任务交给隔离的子 Agent。

内置子 Agent：

| 名称 | 能力 |
| --- | --- |
| `explore` | 快速只读侦察 |
| `researcher` | 更深入的只读调研 |
| `writer` | 可产生 edit/write 的待确认 diff，合并回父级变更集 |

要点：

- 子 Agent **看不到**当前对话，所以交给它的指令必须自包含。
- 子工具与父权限取交集，writer 可生成多文件变更；不提供 exec/browser/MCP 或递归委派。
- 续跑绑定父会话、角色和权限版本，收权或跨会话后不能复用旧上下文。
- 最多 3 个只读任务可以并行执行。
- `background=true` 只用于独立的只读工作，完成时会通知你。
- 返回值只有子 Agent 的最终报告，不含中间过程。

## 上下文与整理

Agent 每轮发给模型的内容由四层组成：唯一 system、压缩检查点、按窗口装箱的历史、本轮 user。

- **工作记忆**（`contextSummary`）是结构化摘要，只在上下文浮层里展示字段数和更新时间，不展示正文。
- **压缩检查点**只在历史真的装不下时才注入模型，避免无故打断缓存。
- 点上下文浮层里的「整理」或发送 `/compact` 会立即整理一次：先用模型合并工作记忆，模型不可用时降级为本地规则摘要，然后把已落盘的模型 transcript 改写成「检查点 + 最近一段对话」。
- 点击后按钮立刻变成「整理中…」并禁用，浮层就地显示进度；同一会话不会并发跑多份摘要。
- 没有新的未整理消息时直接返回「上下文已是最新」，不再发起一次模型请求。
- 整理回执会说明摘要来源和实际丢弃的历史条数；如果模型摘要失败，回执里会带上失败原因，不会假装成功。

::: tip 整理不会删除聊天记录
整理只改写发给模型的 transcript，界面上的消息历史保持完整，可以随时回看。
:::

## 记忆

会话记忆默认关闭，开启后会按知识库维度管理，并过滤常见的敏感信息。

在 **设置 → Agent 记忆** 中查看和管理。
