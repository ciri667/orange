# 会话与 Agent

## 会话

一个会话是一段独立的对话上下文，绑定一组你授权的知识库。

- 会话有独立的标题、模型和上下文状态。
- 会话可以开启**计划模式**。
- 会话可以按需开启**记忆**（默认关闭）。
- 会话可以设置**安全级别**（决定 Agent 能用哪些工具）。

## 安全级别

安全级别决定 Agent 的工具集和写入行为。默认是「基础」。

| 级别 | 值 | 能做什么 |
| --- | --- | --- |
| 基础 | `basic` | 在知识库内检索、读取、生成 diff；**不能**创建文件夹；写入必须逐次确认 |
| 进阶 | `advanced` | 增加通用文件工具（如创建文件夹）；写入仍需确认 |
| 完全 | `autonomous` | 允许访问知识库根目录之外的合规绝对路径；校验通过后自动落盘，不再中途打断确认 |

::: danger 关于「完全」级别
完全级别会跳过写入确认，由 Agent 直接落盘（仍会做路径校验和 hash 校验）。除非你清楚风险，否则建议保持「基础」或「进阶」。
:::

::: info 高权限工具是「不可见」而不是「软拒绝」
工具在注册层就按会话级别裁剪，模型根本看不到没有权限的工具，而不是靠执行时拒绝。
:::

## 计划模式

开启计划模式后：

- Agent 只注册只读工具（`search` / `read` / `list`）+ `task`。
- `edit` / `write` / `run` 对模型**不可见**，写入在运行时层面就不可能发生。
- Agent 先给出编号的执行计划，你确认后才退出计划模式执行。

## 子 Agent（`task` 工具）

`task` 是唯一的编排工具，用来把一个复杂、多跳的任务交给隔离的子 Agent。

内置子 Agent：

| 名称 | 能力 |
| --- | --- |
| `explore` | 快速只读侦察 |
| `researcher` | 更深入的只读调研 |
| `writer` | 可产生 edit/write 的待确认 diff，合并回父级变更集 |

要点：

- 子 Agent **看不到**当前对话，所以交给它的指令必须自包含。
- 最多 3 个只读任务可以并行执行。
- `background=true` 只用于独立的只读工作，完成时会通知你。
- 返回值只有子 Agent 的最终报告，不含中间过程。

## 上下文与整理

Agent 每轮发给模型的内容由四层组成：唯一 system、压缩检查点、按窗口装箱的历史、本轮 user。

- **工作记忆**（`contextSummary`）是结构化摘要，只在上下文浮层里展示字段数和更新时间，不展示正文。
- **压缩检查点**只在历史真的装不下时才注入模型，避免无故打断缓存。
- 点上下文浮层里的「整理」或发送 `/compact` 会立即整理一次：先用模型合并工作记忆，模型不可用时降级为本地规则摘要，然后把已落盘的模型 transcript 改写成「检查点 + 最近一段对话」。
- 点击后按钮立刻变成「整理中…」并禁用，浮层就地显示进度；同一会话不会并发跑多份摘要。
- 没有新的未整理消息时直接返回「上下文已是最新」，不再发起一次模型请求。
- 整理回执会说明摘要来源和实际丢弃的历史条数；如果模型摘要失败，回执里会带上失败原因，不会假装成功。

::: tip 整理不会删除聊天记录
整理只改写发给模型的 transcript，界面上的消息历史保持完整，可以随时回看。
:::

## 记忆

会话记忆默认关闭，开启后会按知识库维度管理，并过滤常见的敏感信息。

在 **设置 → Agent 记忆** 中查看和管理。
