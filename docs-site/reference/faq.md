# FAQ 与排错

## 检索相关

### 明明有这篇笔记，Agent 却说找不到

- `search` 默认只覆盖 **Markdown**。TXT 能被 `read` 读到，但不参与全文索引，也不产生知识库引用。
- DOCX / PDF 不参与检索，只能用 `read` 只读抽取。
- 检查这篇笔记所在的知识库是否在当前会话的授权范围里。

### 语义检索显示回退到关键词了

常见原因：

- embedding 服务不可用（探测一下连通性）。
- 索引为空，或还在构建中。
- provider / model 配置变了，索引需要重建。

过程面板会显示 `keyword_fallback`，并给出原因。

### 引用里的行号和我看到的对不上

引用定位是「标题路径 · L起-L止」，基于被索引时的文件内容。文件之后被外部修改过，行号可能偏移。

## 写入相关

### Agent 说改了，但文件没变

检查会话的安全级别和是否在计划模式：

- 计划模式下 `edit` / `write` 对模型不可见，不会产生写入。
- 基础 / 进阶级别需要你在 diff 界面确认。

### 确认写入时报 hash 不匹配

说明你审阅 diff 之后，文件被别的程序改过。橘记会拒绝覆盖，重新生成一次 diff 再确认即可。

### 想关掉每次确认

把会话安全级别调到「完全」（`autonomous`）。但这样 Agent 会在校验通过后直接落盘，请谨慎。

## 模型相关

### 本地 Ollama / LM Studio 连不上

- 确认服务已经启动，地址填的是本机地址。
- 本地服务强制使用回环地址，不能用远程地址冒充本地。

### 云端模型提示需要授权上传

云端 embedding 需要显式同意上传（`allow_cloud_upload`），授权绑定当前配置指纹。改了配置就需要重新授权。

## 浏览器相关

### 浏览器功能打不开

- 功能默认关闭，需要先在设置里启用。
- 需要先下载浏览器内核。
- 只有本机交互会话、进阶级别及以上可用。

## IM 相关

### 在群里发消息机器人没反应

群聊必须**直接 @ 机器人**。

### 收到「未授权」提示

发送人或群还没有被允许。去 **设置 → 即时通讯 → 待授权对象** 里点允许，然后保存设置。

## 开发相关

### Windows 上 `cargo` 找不到

首次安装 Rust 后需要重启终端或 IDE，让 `cargo` 进入 `PATH`。可以用下面的命令确认环境：

```powershell
rustup default stable-msvc
npx tauri info
```
