# 数据与隐私边界

## 数据去向一览

| 内容 | 处理方式 |
| --- | --- |
| 笔记文件 | 保存在你选择的本地目录；移除知识库授权不会删除原文件 |
| 检索范围 | 工作区档限所选知识库和启用的 Skill 资源；完全档可访问工作区外资源 |
| 模型密钥 | 保存到系统 Keychain / 凭据管理器；界面与日志不回显明文 |
| 云端请求 | 仅在启用云端模型并发起 Agent 请求时，发送给所配置的模型服务 |
| 写入变更 | 结构化工具经 diff 或影响清单与严格冲突检查；无需审批档自动应用本次新变更；真实命令和外部服务按操作审批执行 |
| 语音音频 | 识别在本机完成，音频不上传 |
| 浏览器截图 | 只用于面板和回执展示，不发给模型 |
| 语义索引 | 向量以 BLOB 存在本地 SQLite；云端 embedding 需要显式授权 |

## 本地运行的可能性

使用本地模型和本地 embedding，并保持外部工具关闭，可以在本机处理笔记。启用并授权联网、浏览器、MCP 或真实命令后，操作可能访问外部服务；模型配置与操作权限分别控制。

命令以当前用户真实权限执行，过滤明显秘密环境变量，不主动注入 Keyring 凭据、不请求管理员权限；不提供文件系统沙箱或整机资源配额。命令内部修改不逐项展示 diff，失败或取消也可能产生副作用。

## 日志

- 运行日志分级记录，可按知识库查看。
- 语义索引的进度事件不携带输入文本。
- 模型 API Key 不会出现在界面和日志里。

## 审计

请求审计是本地记录，可以回看每次 Agent 请求，用于自查。

## 关于网页内容

从联网搜索、网页抓取或内嵌浏览器拿到的内容，一律视为**不可信数据**，不会被当作指令执行。
