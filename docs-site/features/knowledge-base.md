# 知识库与文件

## 目录树

工作台左侧展示当前知识库的目录树，可以浏览文件夹、Markdown 笔记和受支持的文档。

## 编辑与预览

- 编辑 Markdown 和 TXT。
- 预览 Markdown 渲染效果。
- 查看、导出、重命名、删除本地文件。

## 文档读取（只读）

DOCX 和 PDF 会被提取成文本供 Agent 读取：

| 格式 | 返回内容 |
| --- | --- |
| DOCX / DOCM | 提取的文本与结构块（标题层级、编号、表格行列、批注、脚注、页眉页脚）；无可靠物理页码，可用 `block` 或 `heading` 定位 |
| PDF | 按页提取的文本、页码和页数；可用 `page`、`pageEnd` 读取指定页或页区间，用 `block` 读取单个结构块 |

这两类文档**永远不会被编辑**。它们也会进入文档 chunk 索引（关键词 + 可选语义），`search` 的 `fileTypes` 支持 `docx`/`pdf`，返回带页码或结构块号的引用，点击引用可直接跳到对应页/块。

DOCX 阅读器提供「版式视图 / 文本视图」切换：版式视图用 `docx-preview` 在本地渲染表格、图片、页眉页脚和分页；文本视图展示后端抽取的结构块，并按引用块号高亮。版式渲染失败会自动回退文本视图。

PDF 阅读器用 `pdfjs-dist` 画布渲染，支持上一页/下一页、页码输入和总页数，并能用后端文本层搜索后跳页；引用点击可直接换到对应页。

扫描页、图表和文档内图片需要支持视觉输入的多模态模型直接读取，不经过 OCR；未启用视觉模型时会提示无法读取页面图片。PDF 页面由内置的纯 Rust 光栅化器渲染成图片，不需要额外安装 PDFium 或任何 OCR 组件。

`.docm` 按 DOCX 读取，但宏不会运行；旧版 `.doc` 不支持，请另存为 `.docx`。加密的 PDF/DOCX 会返回明确的加密提示，目前不支持输入密码。

## 历史记录

文件修改有本地历史，可以在文档历史里回看和恢复。

## 显式附带文件

在会话里可以用 `@` 显式附带某个文件，让 Agent 直接读它，而不必先检索。
