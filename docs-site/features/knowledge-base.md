# 知识库与文件

## 目录树

工作台左侧展示当前知识库的目录树，可以浏览文件夹、Markdown 笔记和受支持的文档。

## 编辑与预览

- 编辑 Markdown 和 TXT。
- 预览 Markdown 渲染效果。
- 查看、导出、重命名、删除本地文件。

## 文档读取（只读）

DOCX 和 PDF 会被提取成文本供 Agent 读取：

| 格式 | 返回内容 |
| --- | --- |
| DOCX | 提取的文本与结构块 |
| PDF | 提取的文本与页码 |

这两类文档**永远不会被编辑**。

## 历史记录

文件修改有本地历史，可以在文档历史里回看和恢复。

## 显式附带文件

在会话里可以用 `@` 显式附带某个文件，让 Agent 直接读它，而不必先检索。
