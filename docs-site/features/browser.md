# 内嵌浏览器

内嵌浏览器让 Agent 在受控的 Chromium 里打开网页、读取元素，并执行点击 / 填表等操作。

::: info 默认关闭
浏览器功能默认关闭。开启后需要显式确认下载固定版本的浏览器内核。
:::

## 开启步骤

1. 打开 **设置 → 内嵌浏览器**。
2. 打开「启用内嵌浏览器」开关并保存。
3. 点击「下载浏览器内核」，等待下载、校验和解压完成。
4. 点击右侧内容区的 **+ → 新建浏览器**，打开网页页签。

下载会显示进度；没有 Content-Length 时只展示实际下载量，不会伪造百分比。可以切换设置或关闭面板，下载会在后台继续。

## 浏览器内核

- 使用 **Chrome for Testing** 的固定版本。
- 使用独立的 profile，**不读取**你日常浏览器的任何数据。
- 下载包自带 CRC 完整性校验。

## 可用范围

| 条件 | 要求 |
| --- | --- |
| 会话类型 | 仅本机交互会话 |
| 安全级别 | 完全权限，需审批 / 完全权限，无需审批；Plan 禁用 |

## 使用方式

每个网页与会话、终端并列显示在右侧页签栏，不再通过顶栏独立浏览器按钮打开。可以拖拽调整页签顺序，也可以通过「全部页签」列表切换。

Agent 或网页弹窗创建的新页面会加入页签栏，不会切走你正在查看的会话或终端。关闭网页页签会关闭实际页面，关闭最后一个内容页签后右侧栏自动收起。重启橘记只恢复会话页签，不会自动加载网页。

模型通过独立的 `browser` 工具使用浏览器。历史 `run kind=browser` 转换后仍须重新校验权限。

- 只能访问 http / https 页面。
- 所有调用（含读取）在完全权限需审批档逐次确认，无需审批档自动执行；统一审批展示准确参数、目标 URL、标签页和已知操作对象。
- 搜索走固定的搜索地址，不自由拼接。

## 接管与截图

- 面板里有「接管」按钮，你可以随时接手操作。
- 点击网页页签只查看画面，不会中断 Agent；手动导航、点击或输入时才接管。待确认操作使用统一操作审批弹窗；用户接管会取消在途审批并停止本回合后续工具。
- **截图只用于面板和回执展示，不会发给模型。**
