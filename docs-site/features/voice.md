# 语音输入

按住输入框旁的麦克风说话，松开后把中文写进光标位置。

## 特点

- **识别在本机完成**，音频不会上传。
- 使用本机中文语音模型，首次使用需要下载（约 230MB）。

## 配置步骤

1. 打开 **设置 → 语音输入**。
2. 点击「下载中文模型」，等待下载完成。
3. 回到输入框，按住麦克风说话，松开即写入。

## 管理模型

- 「重新下载模型」可以修复损坏的模型。
- 「删除模型」会释放约 230MB 空间，删除后需要重新下载才能继续使用。
