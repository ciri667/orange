# 即时通讯（IM）

把橘记接到聊天软件里，就能在 IM 里直接发消息调用 Agent。

::: warning 可选功能
IM 网关由独立的 sidecar 提供，需要先构建才能使用（见 [开发环境](/dev/getting-started)）。
:::

## 支持的平台

| 平台 | id | 连接方式 |
| --- | --- | --- |
| 飞书 / Lark | `feishu` | 长连接订阅 `im.message.receive_v1` 和 `card.action.trigger` |
| QQ 官方机器人 | `qq` | WebSocket |
| 个人微信 | `weixin` | 腾讯官方 iLink / OpenClaw 接口，扫码登录 |
| 企业微信 | `wecom` | 智能机器人 WebSocket 长连接 |

## 配置步骤

1. 打开 **设置 → 即时通讯**，选择平台标签页。
2. 打开「启用 xxx 集成」。
3. 填写该平台需要的凭据，点击「保存密钥」。
4. 设置默认知识库范围。
5. 点击「启动」，确认网关状态为「运行中」。

## 各平台要点

### 飞书 / Lark

在飞书开放平台创建应用，填写 AppID / AppSecret，开启长连接事件订阅。

### QQ 官方机器人

在 [q.qq.com](https://q.qq.com) 创建机器人，填写 AppID / Secret。发送 API 可能要求配置出站 IP 白名单。

### 个人微信

使用腾讯官方 iLink / OpenClaw 接口，在设置页扫码登录。需要较新的手机微信，且客户端包含 ClawBot 插件。

### 企业微信

在企业微信后台「管理工具 → 智能机器人」以 API 模式创建，填写 BotId / Secret 和机器人名称（需与后台显示名一致）。无需公网回调。

## 白名单

IM 消息默认**不信任**任何发送方。

- 收到未授权消息后，发送人和群会自动出现在「待授权对象」里。
- 点击「允许用户」/「允许群聊」后自动保存并生效。
- 也可以手动填写允许的用户 ID / 群 ID（每行一个）。
- **私聊必须授权发送人**；群聊必须**直接 @ 机器人**才会响应。

## 安全边界

- IM 消息只能检索「默认知识库范围」里配置的知识库。
- **写入类请求仍然只生成待确认 diff**，不会直接落盘。
- IM 会话不能执行 Skill 脚本，也看不到 MCP 工具。
- 内置命令（`/help`、`/status`、`/new`、`/compact`）在鉴权和去重之后被拦截，不会进入模型。

## 状态解读

设置页底部会显示：

```
网关：运行中 / 未运行 · 连接：已收到事件 / 未确认 · 平台：<domain>
```

「未确认」表示网关已启动但还没收到过平台事件。
