# 内置命令

在 Agent 输入框里输入 `/` 会打开命令选择器。内置命令排在 Skills 前面，在同一个列表里展示。

命令在提交时被拦截并直接执行，**不会**变成一条聊天消息。输入未知的 `/xxx` 不会报错，会当作普通提问处理。

## 命令列表

| 命令 | 别名 | 说明 | 桌面端 | IM |
| --- | --- | --- | --- | --- |
| `/help` | — | 查看全部内置指令说明 | ✅ | ✅ |
| `/status` | — | 查看当前会话、模型与上下文状态 | ✅ | ✅ |
| `/new` | `/reset`、`/clear` | 开启新的 Agent 会话 | ✅ | ✅ |
| `/compact` | — | 整理当前会话上下文 | ✅ | ✅ |
| `/rename` | `/title` | 重命名当前会话（`/rename <标题>`） | ✅ | ❌ |

::: info 单一事实来源
这份列表来自 `src-tauri/src/builtin_commands.rs` 里的唯一注册表。桌面端 `/` 选择器、`/help` 文本和 IM 解析都读同一份数据，所以三者不会漂移。
:::

## 在 IM 里使用

飞书 / QQ / 微信 / 企业微信里也可以直接发送内置命令。命令在完成鉴权、去重和群聊 @ 判断之后被拦截，**不会**进入模型。

`/rename` 只在桌面端可用。
