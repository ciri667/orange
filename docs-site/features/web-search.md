# 联网搜索

让 Agent 通过 `search` 工具的 `target=web` 搜索公开网页。

::: info 默认关闭
联网搜索默认关闭。打开后，基础、进阶和完全级别都可以使用。
:::

## 支持的搜索供应商

| 供应商 | id |
| --- | --- |
| Tavily | `tavily` |
| Brave Search | `brave` |
| Exa | `exa` |
| Serper | `serper` |

## 配置步骤

1. 打开 **设置 → 联网搜索**。
2. 打开「允许 Agent 联网搜索」。
3. 选择搜索供应商。
4. 粘贴 API Key 并保存。
5. 点击「探测」确认可用。

密钥保存后不会回显，留空表示不修改。状态会显示为：可用 / 密钥无效 / 限流 / 网络错误 / 未配置密钥。

## 返回什么

`target=web` 只返回标题、URL 和简短摘要，**不会下载页面内容**。

- 默认返回 5 条，最多 8 条。
- 需要正文时，Agent 会用 `read` 的 `url` 参数单独抓取某一页。

::: warning 网页内容是不可信数据
搜索结果和网页正文都属于不可信数据，Agent 不会把它们当作指令执行。
:::
